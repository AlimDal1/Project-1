# Humanitarian Data Pipeline (ETL)

## Overview
This project demonstrates a simple ETL (Extract, Transform, Load) pipeline designed to process raw humanitarian data into clean, structured datasets.

## Features
- Data extraction from CSV files
- Data cleaning and preprocessing
- Duplicate removal and missing value handling
- KPI generation (age groups)
- Output of clean datasets for reporting

## Tech Stack
- Python
- Pandas
